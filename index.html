FaceID en el Aula

Sistema de reconocimiento facial con CNN y despliegue móvil

Grupo: Composers

El Problema

Desafío de Identificación Automatizada

Desarrollar un sistema capaz de identificar automáticamente a los miembros del grupo con alta precisión en tiempo real, demostrando la viabilidad de estas tecnologías en entornos educativos o de control de acceso.

El sistema debe funcionar bajo diferentes condiciones de iluminación, expresión facial y ángulos, con una precisión superior al 90% y un tiempo de inferencia menor a 500ms por frame.

Automatización con Deep Learning

Aprovechar el potencial de las Redes Neuronales Convolucionales para el reconocimiento de patrones visuales en rostros.

Funcionamiento en Tiempo Real

La aplicación móvil desarrollada con Flutter utiliza el modelo convertido a TensorFlow Lite para realizar reconocimiento facial en tiempo real.

  • Captura de rostro mediante cámara
  • Procesamiento con modelo CNN
  • Identificación del integrante
  • Mostrar nivel de confianza
